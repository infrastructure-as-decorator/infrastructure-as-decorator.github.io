Quickstart REST

The quickstart-rest project is the smallest executable example. It creates a default API Gateway REST API backed by one Lambda function and exposes GET /hello.

It is the runnable counterpart to the Getting Started tutorial. Getting Started builds the same core shape file by file, so cloning this project is optional rather than a prerequisite.

Architecture​

The CDK app creates a QuickstartRestStack. Its LambdaApi construct discovers the decorated handler in lambdas, creates one Lambda function, and connects it to the default REST API. The resulting infrastructure includes the API Gateway REST API, its /hello resource and GET method, the Lambda integration, and the Python Lambda function.

The stack selects runtime Python 3.14 through LambdaApiConfig:

from aws_cdk import Stack, aws_lambda as lambda_
from constructs import Construct
from lambda_api_decorators_cdk import LambdaApi, LambdaApiConfig


class QuickstartRestStack(Stack):
    def __init__(self, scope: Construct, construct_id: str, **kwargs) -> None:
        super().__init__(scope, construct_id, **kwargs)

        config = LambdaApiConfig(
            runtime=lambda_.Runtime.PYTHON_3_14,
        )

        LambdaApi(
            self,
            "Api",
            lambda_path="lambdas",
            config=config,
        )

Because api_type is omitted, this is the default REST API behavior. The handler uses @GET("/hello") and returns the JSON message Hello, world!.

Main files​

quickstart-rest/
├── app.py
├── cdk.json
├── requirements.txt
├── requirements-dev.txt
├── quickstart_rest/
│   └── quickstart_rest_stack.py
├── lambdas/
│   ├── __init__.py
│   ├── hello.py
│   └── requirements.txt
└── tests/
    ├── test_hello.py
    └── test_stack.py

test_hello.py checks the handler response. test_stack.py checks the REST API, GET method, /hello resource, Lambda function, and Python 3.14 runtime. The infrastructure test is skipped when Docker or its CDK dependencies are not available. Consult the source tree and README for the complete implementation.

Run the project​

Run the following from quickstart-rest.

  • Linux/macOS
  • Windows PowerShell
  • Windows CMD
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
pytest -q
cdk synth --quiet
cdk bootstrap
cdk deploy
cdk destroy
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
pytest -q
cdk synth --quiet
cdk bootstrap
cdk deploy
cdk destroy
py -3 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements-dev.txt
pytest -q
cdk synth --quiet
cdk bootstrap
cdk deploy
cdk destroy

Run cdk bootstrap, cdk deploy, and cdk destroy only when AWS credentials are configured. Docker must be running for the infrastructure test and cdk synth; deployment outputs the REST API endpoint, to which you append /hello.

Configuration decorators

Configuration decorators record Lambda options for the CDK package. They do not alter handler execution. Their argument is intentionally not type-checked by this CDK-free package; the consuming builder resolves names and converts values where stated below. All return a decorator.

Example covering all configuration decorators:

from lambda_api_decorators import (
    GET, description, environment, layer, memory_size, name, role,
    runtime, security_group, timeout, vpc,
)

@GET("/configured")
@memory_size(1024)
@timeout(15)
@environment("STAGE", "TABLE_NAME")
@layer("shared")
@runtime("python3.12")
@security_group("api")
@vpc("private")
@role("api-role")
@description("Configured endpoint")
@name("configured-handler")
def configured(event, context):
    return {"statusCode": 200, "body": "ok"}

memory_size​

Signature: memory_size(arg).

Returns: a decorator that returns the decorated callable.

memory_size(arg) sets the function memory option. In CDK, the value is passed to PythonFunction(memory_size=...).

timeout​

Signature: timeout(arg).

Returns: a decorator that returns the decorated callable.

timeout(arg) records seconds; the builder passes Duration.seconds(arg) to the Lambda function.

environment​

Signature: environment(*eargs, **kwargs).

Returns: a decorator that returns the decorated callable.

environment(*eargs, **kwargs) records environment key names. Positional names and keyword arguments are retained as declaration metadata; the current builder uses positional names to look up custom values. Common environment values are configured with LambdaApiConfig.add_common_environment.

layer​

Signature: layer(*largs, **kwargs).

Returns: a decorator that returns the decorated callable.

layer(*largs, **kwargs) records custom layer keys. The builder resolves each key through its custom-layer registry; repeated declarations aggregate.

runtime​

Signature: runtime(arg).

Returns: a decorator that returns the decorated callable.

runtime(arg) selects a custom runtime key. Built-in keys include python3.8 through python3.14 in the current builder; a custom registry entry with the same key is overwritten by that built-in alias.

security_group​

Signature: security_group(*sgargs).

Returns: a decorator that returns the decorated callable.

security_group(*sgargs) records custom security-group keys. The builder resolves each key and combines them with common security groups.

vpc​

Signature: vpc(arg).

Returns: a decorator that returns the decorated callable.

vpc(arg) selects a custom VPC key. The resolved (vpc, vpc_subnets) pair is passed to the Lambda function.

role​

Signature: role(arg).

Returns: a decorator that returns the decorated callable.

role(arg) selects a custom IAM role key for the function.

description​

Signature: description(arg).

Returns: a decorator that returns the decorated callable.

description(arg) sets the Lambda description.

name​

Signature: name(arg).

Returns: a decorator that returns the decorated callable.

name(arg) sets the Lambda function name. Without it, the builder uses the discovered logical ID.

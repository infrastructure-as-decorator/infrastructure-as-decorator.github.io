LambdaApiConfig

LambdaApiConfig is the reusable, high-level configuration interface for LambdaApi. It stores defaults and registries, then creates an isolated internal builder snapshot for each build.

Constructor​

Constructor signature: LambdaApiConfig(*, runtime=None, timeout=None, memory_size=None, vpc=None, vpc_subnets=None, role=None, layers=None, security_groups=None, environment=None, dynamodb_tables=None, s3_buckets=None, authorizers=None, default_authorizer=None)

Parameters:

  • runtime (Optional[lambda_.Runtime]) – Default Lambda runtime. Default: None.

  • timeout (Optional[Duration]) – Default Lambda timeout. Default: None.

  • memory_size (Optional[int]) – Default Lambda memory size. Default: None.

  • vpc (Optional[ec2.IVpc]) – Default VPC. Default: None.

  • vpc_subnets (Optional[ec2.SubnetSelection]) – Subnet selection paired with vpc. Default: None.

  • role (Optional[iam.IRole]) – Default Lambda execution role. Default: None.

  • layers (Optional[Sequence[lambda_.ILayerVersion]]) – Layers common to every discovered function. Default: None.

  • security_groups (Optional[Sequence[ec2.ISecurityGroup]]) – Security groups common to every discovered function. Default: None.

  • environment (Optional[Mapping[str, str]]) – Environment values common to every discovered function. Default: None.

  • dynamodb_tables (Optional[Mapping[str, dynamodb.ITable]]) – Logical table registry used by grant_dynamodb. Default: None.

  • s3_buckets (Optional[Mapping[str, s3.IBucket]]) – Logical bucket registry used by grant_s3. Default: None.

  • authorizers (Optional[Mapping[str, object]]) – Logical REST or HTTP authorizer registry. Default: None.

  • default_authorizer (Optional[str]) – Registered authorizer key applied to routes without an override. Default: None.

Input sequences and mappings are copied. CDK resource objects retain their identity. A registry key must be a non-empty string; duplicate table, bucket, or authorizer keys raise ValueError. Invalid resource objects raise TypeError.

Example using the constructor and registries:

from aws_cdk import Duration, aws_dynamodb as dynamodb, aws_lambda as lambda_
from lambda_api_decorators_cdk import LambdaApiConfig

config = LambdaApiConfig(
    runtime=lambda_.Runtime.PYTHON_3_12,
    timeout=Duration.seconds(20),
    memory_size=512,
    vpc=app_vpc,
    vpc_subnets=private_subnets,
    role=execution_role,
    layers=[shared_layer],
    security_groups=[lambda_security_group],
    environment={"STAGE": "prod"},
    dynamodb_tables={"orders": orders_table},
    s3_buckets={"uploads": uploads_bucket},
    authorizers={"users": users_authorizer},
    default_authorizer="users",
)
config.add_custom_runtime("legacy", lambda_.Runtime.PYTHON_3_11)
config.add_custom_layer("extra", extra_layer)
config.add_common_environment("REGION_NAME", "us-east-1")

The names used by the decorators are aliases in the custom registries; the constructor defaults above are CDK objects or values applied to every function.

Defaults​

set_default_runtime(runtime: Optional[lambda_.Runtime]) -> None​

Sets the runtime default, or clears it with None.

set_default_timeout(timeout: Optional[Duration]) -> None​

Sets the timeout default, or clears it with None.

set_default_memory_size(memory_size: Optional[int]) -> None​

Sets the memory default, or clears it with None.

set_default_vpc(vpc: Optional[ec2.IVpc], vpc_subnets: Optional[ec2.SubnetSelection] = None) -> None​

Sets or clears the VPC default. The pair is retained as (vpc, vpc_subnets).

set_default_role(role: Optional[iam.IRole]) -> None​

Sets the execution-role default, or clears it with None.

Common configuration​

add_common_layer(layer: lambda_.ILayerVersion) -> None​

Adds a layer for every discovered function; identical objects are not added twice.

add_common_security_group(security_group: ec2.ISecurityGroup) -> None​

Adds a security group for every function; identical objects are de-duplicated.

add_common_environment​

Signature: add_common_environment(key: str, value: str) -> None.

Adds or replaces a common environment entry.

Custom registries​

add_custom_runtime(key: str, runtime: lambda_.Runtime) -> None​

Registers or replaces the runtime selected by @runtime(key).

add_custom_role(key: str, role: iam.IRole) -> None​

Registers or replaces the role selected by @role(key).

add_custom_layer(key: str, layer: lambda_.ILayerVersion) -> None​

Registers or replaces the layer selected by @layer(key).

add_custom_environment(key: str, value: str) -> None​

Registers or replaces the value selected by @environment(key).

add_custom_security_group(key: str, security_group: ec2.ISecurityGroup) -> None​

Registers or replaces the group selected by @security_group(key).

add_custom_vpc(key: str, vpc: ec2.IVpc, vpc_subnets: Optional[ec2.SubnetSelection] = None) -> None​

Registers or replaces the (vpc, vpc_subnets) pair selected by @vpc(key).

add_dynamodb_table(key: str, table: dynamodb.ITable) -> None​

Registers a named table for grant_dynamodb.

add_s3_bucket(key: str, bucket: s3.IBucket) -> None​

Registers a named bucket for grant_s3.

add_authorizer(key: str, authorizer: object) -> None​

Registers a CDK REST or HTTP route authorizer. The object must implement IAuthorizer or IHttpRouteAuthorizer; duplicate keys and invalid keys or objects raise ValueError or TypeError.

set_default_authorizer(key: Optional[str]) -> None​

Sets or clears the registered default authorizer. A non-None key must already be registered, otherwise KeyError is raised. On a route, @public overrides this default and @authorizer(key) selects a route-specific registered key. With no default, routes without an explicit authorizer are public; the CDK construct emits a diagnostic warning.

The decorator @runtime("python3.12") names a registry alias. The constructor's runtime= argument is the CDK runtime object used as the default; they are distinct mechanisms. The same distinction applies to other decorator aliases and the common/custom registries.
